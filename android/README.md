# 🤖 Personal AI Hub - Android Native App

Aplikasi Android murni (*Pure Native*) berbasis **Kotlin 2.1**, **Jetpack Compose (BOM 2025.01)**, Retrofit, Kotlinx Serialization, Preferences DataStore, dan arsitektur modular Core & Features.

## 🚀 Fitur Utama
- **Modern Jetpack Compose**: Arsitektur UI deklaratif dengan Material 3, dynamic theme, dan bento cards.
- **DeepLinkGuard & DeepLinkManager**: Navigasi ke aplikasi satelit (F-Tracker & Task Management) dengan verifikasi .
- **AI Briefing & Chat**: Terhubung ke backend Go Fiber v2 dan Google Gemini Function Calling.
- **Preferences DataStore**: Penyimpanan sesi dan token aman.
- **Real-Time Streaming**: Server-Sent Events (SSE) via OkHttp SSE.
